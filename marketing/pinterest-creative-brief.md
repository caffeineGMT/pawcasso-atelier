## Brand Guidelines

### Visual Identity
- **Primary Color:** Gold (#F4E4C1) - use sparingly for accents
- **Background:** Black (#000000) or White (#FFFFFF)
- **Text Color:** White on dark, Black on light
- **Font:** Inter (sans-serif) - already using on website
- **Logo:** Minimal usage, small watermark in corner

### Brand Voice
- **Tone:** Elegant, approachable, artistic
- **Language:** Simple, clear, benefit-focused
- **Avoid:** Overly cutesy, gimmicky, salesy

### Pinterest-Specific Guidelines
- **Text Overlay:** Maximum 20% of image (Pinterest policy)
- **Readability:** High contrast, large fonts (min 24pt)
- **Mobile-First:** 80% of Pinterest users on mobile
- **Vertical Focus:** 2:3 aspect ratio performs best

## Design Tool Setup

### Option 1: Canva (Recommended for Beginners)

**Setup:**
1. Go to [canva.com](https://www.canva.com/)
2. Create free account (or Pro for templates)
3. Click "Custom Size" → 1000 × 1500 px
4. Search "Pinterest Pin" templates for inspiration

**Workflow:**
1. Upload all gallery WebP images to Canva
2. Create 8 separate designs (1 per pin)
3. Use templates as starting point, customize
4. Download as PNG (high quality)

**Canva Pros:**
- Easiest to use
- Built-in Pinterest templates
- Stock photos/icons available
- Quick iterations

**Canva Cons:**
- Limited customization
- Watermark on free plan
- Less professional

---

### Option 2: Figma (Recommended for Professional Results)

**Setup:**
1. Go to [figma.com](https://www.figma.com/)
2. Create free account
3. New file → Create frame (1000 × 1500px)
4. Name frames Pin-1, Pin-2, etc.

**Workflow:**
1. Drag WebP images into Figma
2. Create 8 frames (artboards)
3. Design each pin using components
4. Export as PNG @2x (2000 × 3000px for retina)

**Figma Pros:**
- Professional results
- Pixel-perfect control
- Reusable components
- Free for individuals

**Figma Cons:**
- Steeper learning curve
- More time-consuming
- Need design skills

---

### Option 3: Adobe Express (Quick & Easy)

**Setup:**
1. Go to [adobe.com/express](https://www.adobe.com/express)
2. Sign in with Adobe ID (free)
3. Search "Pinterest Pin" templates

**Workflow:**
1. Choose template
2. Replace images with your gallery photos
3. Customize text
4. Download as PNG

**Adobe Express Pros:**
- Professional templates
- Easy customization
- Quick turnaround
- Mobile app available

**Adobe Express Cons:**
- Limited free templates
- Less control than Figma
- Subscription for best features

## Technical Specifications

### Required Specs:
- **File Format:** PNG (preferred) or JPEG
- **Dimensions:** 1000 × 1500 pixels (2:3 aspect ratio)
- **File Size:** <20MB (Pinterest limit)
- **Color Mode:** RGB
- **Resolution:** 72-300 DPI (screen resolution)

### Recommended Specs:
- **Export Size:** 2x resolution (2000 × 3000px) for retina displays
- **Compression:** Moderate (balance quality vs file size)
- **Format:** PNG for graphics with text, JPEG for photo-heavy pins

### Pinterest Platform Requirements:
- **Aspect Ratios Accepted:** 2:3 (standard), 1:1 (square), 9:16 (story), 1:2.1 (long)
- **Best Performing:** 2:3 (our chosen format)
- **Text Overlay Limit:** <20% of image area
- **Safe Zone:** Keep important elements away from edges (50px margin)

- [ ] Image is sharp, not pixelated

### Content:
- [ ] Headline is clear and benefit-focused

- [ ] CTA is action-oriented
- [ ] Brand voice is consistent

### Technical:
- [ ] Dimensions: 1000 × 1500px
- [ ] File format: PNG
- [ ] File size: <5MB (ideally <2MB)
- [ ] Text overlay: <20% of image
- [ ] Safe zone respected (50px margins)

### Pinterest Policy:
- [ ] No misleading claims
- [ ] Price is visible and accurate

## Creative Best Practices (Pinterest-Specific)

### Do's:
✅ Use vertical 2:3 aspect ratio
✅ Feature lifestyle imagery when possible
✅ Include branding (subtle logo)
✅ Show product in context
✅ Use high-contrast colors
✅ Mobile-optimize text size
✅ Add value/benefits
✅ Include pricing
✅ Test multiple variations

### Don'ts:
❌ Exceed 20% text overlay
❌ Use low-resolution images
❌ Make claims you can't back up
❌ Copy competitor pins
❌ Use clickbait headlines
❌ Overcrowd with text
❌ Ignore mobile view
❌ Forget CTAs
