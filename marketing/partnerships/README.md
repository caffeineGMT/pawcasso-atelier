# Pawcasso Atelier - Partnership Outreach Program

## 📁 Directory Contents

This directory contains all materials for the **Partnership Outreach** marketing campaign targeting pet brands, veterinary clinics, and pet photographers.

### Files:

1. **`partner-database.json`** - Comprehensive database of 50 potential partners
   - 20 pet brands (BarkBox, Chewy, Rover, etc.)
   - 15 veterinary clinics (Banfield, VCA, Lap of Love, etc.)
   - 15 pet photographers (The Dogist, Sophie Gamand, etc.)
   - Includes contact info, estimated reach, partnership type, and notes

2. **`partner-one-pager.html`** - Professional partnership proposal one-pager
   - Print to PDF for email attachments
   - Includes value prop, benefits, partnership models, and CTA
   - Fully branded with Pawcasso design system
   - **To generate PDF:** Open in browser → Print → Save as PDF

3. **`email-templates.md`** - Complete email outreach playbook
   - 3 category-specific templates (Pet Brands, Vet Clinics, Photographers)
   - Follow-up email sequences (3 follow-ups per partner)
   - Response handling templates
   - Personalization checklists
   - A/B testing guidelines

4. **`outreach-tracker.csv`** - CRM tracking spreadsheet
   - All 50 partners with contact details
   - Status tracking fields (Not Contacted → Active Partnership)
   - Date tracking for outreach cadence
   - Notes and next actions
   - **Import into:** Google Sheets, Airtable, or Excel

5. **`IMPLEMENTATION-GUIDE.md`** - Step-by-step execution plan
   - 4-week outreach timeline
   - Pre-launch checklist
   - Partnership onboarding process
   - Call scripts and objection handling
   - Success metrics and KPIs
   - Tools and budget estimates

6. **`partnership-agreement-template.md`** - Legal agreement template
   - Standard terms for all partnership types
   - Commission structures
   - Term length and termination clauses
   - **Note:** Review with legal counsel before use

7. **`discount-codes-setup.md`** - Stripe discount code configuration
   - How to create partner-specific codes
   - Tracking setup for attribution
   - Bulk code generation scripts

## 🚀 Quick Start

### Step 1: Set Up Infrastructure (1-2 hours)
1. Create partnerships@pawcasso-atelier.com email
2. Import `outreach-tracker.csv` into Google Sheets
3. Set up Calendly for partnership calls
4. Print `partner-one-pager.html` to PDF

### Step 2: Prepare Materials (2-3 hours)
1. Review and personalize `email-templates.md` for your voice
2. Create 15-20 sample portrait gallery
3. Set up Stripe discount codes (see `discount-codes-setup.md`)
4. Review partnership agreement with legal

### Step 3: Begin Outreach (Week 1)
1. Follow the 4-week timeline in `IMPLEMENTATION-GUIDE.md`
2. Start with 10 "Very High" priority partners (Monday)
3. Send 10 "High" priority partners (Wednesday)
4. Track everything in `outreach-tracker.csv`
5. Respond to inquiries within 4 hours

### Step 4: Track & Optimize (Ongoing)
1. Update tracker after every email/call/response
2. Monitor open rates and response rates
3. Adjust templates based on feedback
4. Schedule partnership calls via Calendly
5. Celebrate wins!

## 🚨 Common Questions

### Q: What if a partner wants a higher commission?
**A:** Be flexible but protect margins. Max 30% for exclusive partners. Remember: $9 × 30% = $2.70 commission, $6.30 net = 70% gross margin.

### Q: How do we track which orders came from which partner?
**A:** Use unique discount codes per partner (e.g., BARKBOX10, THEDOGIST10). Track in Stripe or manually in spreadsheet.

### Q: What if a partner wants to be paid upfront?
**A:** Don't do it. Commission-based only. If they insist, offer a hybrid (small upfront + lower commission).

### Q: Should we offer free portraits to partners to test?
**A:** Yes! Offer 3-5 free sample portraits to high-value partners. It's a $27-45 CAC but worth it for the right partner.

### Q: What if we can't meet expected order volume?
**A:** Under-promise, over-deliver. Give conservative estimates (5-10 orders/month) and exceed expectations.
