## Technical Specifications

### Video Settings
- **Resolution:** 1920x1080 (1080p)
- **Frame Rate:** 30 fps or 60 fps
- **Aspect Ratio:** 16:9 (horizontal)
- **File Format:** MP4 (H.264 codec)
- **File Size:** <50 MB (for fast loading)

### Screen Recording Tools
- **Mac:** QuickTime Screen Recording or ScreenFlow
- **Windows:** OBS Studio or Camtasia
- **Online:** Loom (but export to MP4)

### Editing Software
- **Beginner:** iMovie (Mac), DaVinci Resolve (free)
- **Intermediate:** Final Cut Pro, Adobe Premiere
- **Quick edits:** Kapwing (online), CapCut (mobile/desktop)

### Music
- **Recommended Track:** Upbeat, magical, modern
- **Sources:**
  - Epidemic Sound (subscription)
  - Artlist (subscription)
  - YouTube Audio Library (free)
  - Suggested: "Inspiring Cinematic" or "Tech Innovation" genre

- **Volume:** Background music at 30-40% volume (don't overpower visuals)

### Text Overlays
- **Font:** Inter, Poppins, or Montserrat (clean, modern sans-serif)
- **Color:** White text with dark shadow/stroke (or gold #C9A96E for brand consistency)
- **Size:** Large enough to read on mobile (minimum 48px)
- **Animation:** Fade in/out, slide up, or scale up

## Screen Recording Checklist

### Pre-Recording Setup
- [ ] Clear browser cache and cookies
- [ ] Close unnecessary tabs/windows
- [ ] Set browser to 1920x1080 viewport (or record at this resolution)
- [ ] Disable notifications (Mac: Do Not Disturb, Windows: Focus Assist)
- [ ] Use Incognito/Private mode (clean UI, no autofill)
- [ ] Prepare test pet photos (high quality, diverse animals)

### Recording Steps

**Scene 1: Upload Photo**
- [ ] Navigate to pawcasso-atelier.vercel.app/order
- [ ] Click "Upload Photo" zone
- [ ] Select Border Collie photo (Alfie)
- [ ] Preview appears (capture this moment)

**Scene 2: Choose Style**
- [ ] Scroll through style options
- [ ] Click "Renaissance"
- [ ] Style preview image updates (capture this)

**Scene 3: Fill Form (abbreviated)**
- [ ] Enter name: "Jane Doe"
- [ ] Enter email: "jane@example.com"
- [ ] Enter pet name: "Alfie"
- [ ] Leave notes blank

**Scene 4: Checkout Button (don't click)**
- [ ] Hover over "Pay $9 - Get Your Portrait" button
- [ ] Capture hover state
- [ ] DO NOT actually submit (or use test mode)

**Scene 5: Show Gallery**
- [ ] Navigate to /gallery page
- [ ] Show grid of portraits
- [ ] Filter by style (Renaissance, Pixar 3D, Needle Felt)

- [ ] Navigate back to /order page
- [ ] Show pricing comparison table
- [ ] Highlight features (1 portrait, 3 portraits, 5 portraits)

### Post-Recording Editing
- [ ] Trim dead space (loading screens, hesitations)
