## Daily Tasks (✓ when complete)

### Morning Check (9 AM) - 3 minutes
- [ ] Check total spend vs. budget pacing (on track?)
- [ ] Review overnight purchases (any conversions?)
- [ ] Check for ad disapprovals (any red flags?)
- [ ] Verify Pixel is firing (green checkmark in Events Manager)

### Afternoon Check (3 PM) - 2 minutes
- [ ] Review CTR on active ads (any below 1%?)
- [ ] Check CPA trends (rising or falling?)
- [ ] Monitor ad fatigue (frequency > 3.0?)
- [ ] Look for audience overlap warnings

---

## Red Flags 🚨 (Take Action Immediately)

### Critical Issues
- [ ] **Ad Disapproved** → Review policy violation, fix, resubmit
- [ ] **Pixel Stopped Firing** → Check website, verify Events Manager
- [ ] **Zero Purchases for 24+ hours** → Check landing page, test checkout
- [ ] **Daily Spend > $100** → Verify budget settings, pause if needed

### Warning Signs
- [ ] **CPA > $70** → Pause worst-performing ad
- [ ] **CTR < 0.8%** → Test new headline or image
- [ ] **Frequency > 4.0** → Refresh creative or expand audience
- [ ] **Budget spent < 50% daily target** → Check delivery status

---

## Performance Tiers

### 🟢 Winning Ads (Keep & Scale)
- CPA ≤ $35
- CTR ≥ 2.0%
- 3+ purchases
- Frequency < 3.0

**Action:** Increase budget by 20%

### 🟡 Testing Ads (Monitor)
- CPA $36-55
- CTR 1.0-2.0%
- 1-2 purchases
- Frequency < 3.5

**Action:** Let run, review in 48 hours

### 🔴 Underperforming Ads (Pause)
- CPA > $60
- CTR < 0.8%
- 0 purchases after $100 spend
- Frequency > 4.0

**Action:** Pause immediately, analyze why

## Weekly Deep Dive (Monday, 30 minutes)

### Review Last 7 Days
- [ ] Total spend vs. budget
- [ ] Total purchases vs. goal
- [ ] Best-performing ad set
- [ ] Best-performing creative
- [ ] Worst-performing ad (pause it)

### Optimization Actions
- [ ] Pause 1-2 worst ads
- [ ] Duplicate best ad with new headline
- [ ] Adjust budget allocation (favor winners)
- [ ] Check for new conversion data (Lookalike update)

### Data Export
- [ ] Download weekly report from Ads Manager
- [ ] Log in performance tracking spreadsheet
- [ ] Update stakeholders (if applicable)

## Decision Tree: Should I Pause This Ad?

```
┌─ Has it spent ≥ $100?
│  ├─ No → Keep running (not enough data)
│  └─ Yes → Continue ↓
│
├─ Is CPA > $60?
│  ├─ No → Keep running
│  └─ Yes → Continue ↓
│
├─ Did it get 0 purchases?
│  ├─ No → Keep running (monitor closely)
│  └─ Yes → PAUSE IT
```

## Troubleshooting Quick Reference

### Low CTR (< 1%)
1. Test brighter, more colorful images
2. Try video ad instead of static
3. Update headline with urgency ("Limited Time")
4. Add social proof ("500+ Happy Customers")

### High CPA (> $60)
1. Pause worst-performing ad
2. Tighten targeting (age 30-50, US only)
3. Check landing page (is conversion rate > 3%?)
4. Refresh creative with UGC content

### Low Conversions
1. Test landing page (A/B test headline)
2. Verify Pixel is tracking Purchase event
3. Check mobile experience (80% of traffic)
4. Test lower price point ($6 sale)

### Ad Fatigue (Frequency > 3.5)
1. Pause ad for 3-5 days
2. Refresh creative (new image, same copy)
3. Expand audience size
4. Duplicate ad to new audience

## Time-Saving Automated Rules

Set up in Ads Manager → Automated Rules:

### Rule 1: Pause High CPA Ads
- **Condition:** CPA > $70 for 2 consecutive days
- **Action:** Pause ad
- **Check:** Daily at 9 AM

### Rule 2: Increase Budget on Winners
- **Condition:** CPA < $30 and Purchases > 3 in last 3 days
- **Action:** Increase ad set budget by 20%
- **Check:** Every 3 days

### Rule 3: Notify on Zero Purchases
- **Condition:** 0 purchases in last 24 hours
- **Action:** Send notification
- **Check:** Daily at 9 AM
