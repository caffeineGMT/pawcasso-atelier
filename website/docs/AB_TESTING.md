# A/B Testing Framework

## Overview

A production-ready A/B testing system for optimizing the upsell modal timing to maximize conversion rates and revenue per impression.

## Architecture

### Components

1. **Experiment Hook** (`src/lib/experiments.ts`)
   - `useExperiment()` - Returns variant value (delay in ms or trigger type)
   - `useExperimentVariant()` - Returns variant name for tracking
   - `trackExperiment()` - Wrapper for Vercel Analytics tracking

2. **UpsellModal** (`src/components/UpsellModal.tsx`)
   - Dynamically adjusts timing based on assigned variant
   - Tracks impressions, accepts, and declines
   - Supports exit-intent variant (mouseleave trigger)

3. **Admin Dashboard** (`src/app/admin/experiments/page.tsx`)
   - Real-time performance metrics by variant
   - Conversion rate visualization
   - Revenue per impression analysis
   - One-click winner promotion

4. **Edge Config API** (`src/app/api/edge-config/route.ts`)
   - Fetches experiment configuration from Vercel Edge Config
   - Supports dynamic variant weights
   - Enables instant winner promotion without code deployment

## Experiment: Upsell Modal Timing

### Variants

| Variant | Configuration | Hypothesis |
|---------|--------------|------------|
| **control** | 2000ms delay | Baseline - current behavior |
| **fast** | 500ms delay | Earlier intervention captures more attention |
| **delayed** | 5000ms delay | More time to browse before interruption |
| **exit-intent** | mouseleave trigger | Catch users as they're about to leave |

### Tracked Events

```typescript
// Modal shown
trackExperiment('upsell_shown', {
  variant: 'fast',
  sessionId: 'abc123'
});

// User accepts upsell
trackExperiment('upsell_accepted', {
  variant: 'fast',
  sessionId: 'abc123',
  product: 'print' // or 'license'
});

// User declines upsell
trackExperiment('upsell_declined', {
  variant: 'fast',
  sessionId: 'abc123'
});
```

### Key Metrics

- **Impressions**: Total modal views per variant
- **Accepts**: Users who clicked "Add to Order"
- **Declines**: Users who clicked "No thanks"
- **Conversion Rate**: `(accepts / impressions) × 100`
- **Revenue**: Total revenue generated by variant
- **Revenue per Impression**: `total_revenue / impressions`

## Setup Instructions

### 1. Local Development

The system works out-of-the-box with mock Edge Config data:

```bash
npm run dev
# Visit http://localhost:3000/admin/experiments
```

### 2. Production Setup

#### Install Vercel Analytics (Server)

```bash
npm install @vercel/analytics/server
```

#### Create Edge Config

1. Go to [Vercel Dashboard](https://vercel.com/dashboard) → Edge Config
2. Click "Create Edge Config"
3. Add experiment configuration:

```json
{
  "experiments": {
    "upsell-modal-timing": {
      "variants": {
        "control": { "weight": 25 },
        "fast": { "weight": 25 },
        "delayed": { "weight": 25 },
        "exit-intent": { "weight": 25 }
      }
    }
  }
}
```

4. Copy the Edge Config connection string
5. Add to Vercel environment variables:

```bash
EDGE_CONFIG=https://edge-config.vercel.com/...
```

#### Update Edge Config API Route

Replace mock data in `src/app/api/edge-config/route.ts`:

```typescript
import { get } from '@vercel/edge-config';

export async function GET() {
  try {
    const experiments = await get('experiments');
    return NextResponse.json({ experiments });
  } catch (error) {
    console.error('Edge Config error:', error);
    return NextResponse.json(
      { error: 'Failed to fetch experiment config' },
      { status: 500 }
    );
  }
}
```

#### Fetch Analytics Data

Create `src/app/api/analytics/experiments/route.ts`:

```typescript
import { unstable_analytics as analytics } from '@vercel/analytics/server';

export async function GET() {
  const [shown, accepted, declined] = await Promise.all([
    analytics.query({
      event: 'upsell_shown',
      groupBy: ['variant'],
      count: true,
    }),
    analytics.query({
      event: 'upsell_accepted',
      groupBy: ['variant', 'product'],
      count: true,
    }),
    analytics.query({
      event: 'upsell_declined',
      groupBy: ['variant'],
      count: true,
    }),
  ]);

  // Process and combine data...
  return NextResponse.json({ shown, accepted, declined });
}
```

Update dashboard to fetch real data:

```typescript
// In src/app/admin/experiments/page.tsx
useEffect(() => {
  async function fetchData() {

```

## Promoting a Winner

### Option 1: Via Edge Config (Recommended)

Update your Edge Config JSON to set a winner:

```json
{
  "experiments": {
    "upsell-modal-timing": {
      "winner": "fast",
      "variants": { ... }
    }
  }
}
```

All users will immediately receive the "fast" variant. No code deployment needed.

### Option 2: Via Admin Dashboard

1. Visit `/admin/experiments`
2. Review performance metrics
3. Click "Promote" on the winning variant
4. Implement the Edge Config update API:

```typescript
// src/app/api/edge-config/update/route.ts
import { getEdgeConfigClient } from '@vercel/edge-config';

export async function POST(request: Request) {
  const { experiment, winner } = await request.json();

  const client = getEdgeConfigClient(process.env.EDGE_CONFIG!);
  await client.set('experiments', {
    [experiment]: { winner }
  });

  return NextResponse.json({ success: true });
}
```

### Option 3: Code Update

Once validated, update `UpsellModal.tsx` directly:

```typescript
// Remove experiment code
const delay = 500; // Hardcoded winning variant
```

Then remove experiment infrastructure in a future cleanup.

## Technical Notes

### Variant Assignment

- Deterministic hash-based assignment using `sessionId`
- Consistent experience across page reloads
- Stored in localStorage for persistence
- Falls back to Edge Config winner if set

### Exit-Intent Implementation

```typescript
// Triggers when cursor leaves viewport from top
const handleMouseLeave = (e: MouseEvent) => {
  if (e.clientY <= 0) {
    setIsOpen(true);
    trackExperiment('upsell_shown', { variant, sessionId });
  }
};
```

### Performance

- No impact on page load (lazy-loaded hooks)
- Edge Config CDN-cached globally
- Analytics tracking batched by Vercel
