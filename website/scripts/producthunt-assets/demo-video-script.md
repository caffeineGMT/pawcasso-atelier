## Production Notes

### Visual Style
- **Resolution:** 1920×1080 (1080p)
- **Aspect Ratio:** 16:9 for YouTube, 1:1 for Instagram
- **Screen Recording:** Use clean browser window (no bookmarks bar, clean desktop)
- **Cursor:** Highlight cursor movements with subtle glow effect
- **Transitions:** Quick crossfades (0.2s), no fancy effects
- **Color Grading:** Maintain black background (#000000) with gold accents (#C9A96E)

### Audio
- **Background Music:** Upbeat, modern, royalty-free (try Epidemic Sound or Artlist)
  - Suggested: Tech/startup vibes, 120-130 BPM
  - Example tracks: "Inspiring Corporate", "Modern Technology", "Creative Minds"
- **Voiceover:** Professional, friendly, conversational tone (not salesy)
  - Record with quality mic (Blue Yeti or similar)
  - Female or neutral voice preferred
- **Sound Effects:** Subtle UI sounds (clicks, whooshes) at 20% volume

### Text Overlays
- **Font:** Inter, weight 600 for headings, 400 for body
- **Animation:** Fade in + slide up (0.3s)
- **Position:** Lower third for main captions, center for CTAs
- **Contrast:** White text with 2px black stroke for readability

### B-Roll Assets Needed
1. High-quality pet photos (5-6 different breeds)
2. Generated portrait examples (at least 12 different combinations)
3. Screenshot of style selection UI
4. Screenshot of final gallery
5. Mockups: canvas print, phone wallpaper, Instagram post

### Recording Tips
- Use Incognito/Private browsing mode (no extensions, clean UI)
- Set browser zoom to 100%
- Close all other tabs except demo tab
- Disable notifications during recording
- Record at 60fps for smooth playback
- Use OBS Studio or ScreenFlow for recording

### Platform-Specific Versions

**YouTube (1:00 version)**
- 16:9 aspect ratio
- Full script as above
- Include captions/subtitles
- End screen with subscribe button + website link

**Instagram/TikTok (0:30 version)**
- 9:16 vertical aspect ratio (1080×1920)
- Condensed script:
  - 0:00-0:08: Upload + style selection
  - 0:08-0:18: Show results (3 portraits)
  - 0:18-0:30: Pricing + CTA
- Larger text (mobile-optimized)
- Hook in first 3 seconds

**Twitter/X (0:45 version)**
- 16:9 or 1:1 aspect ratio
- Auto-play optimized (muted by default)
- Large captions (assume sound off)
- Hook: "AI pet portraits for $9" in first frame
